# Excel-Sales-Dashboard
An interactive Sales Dashboard built using Microsoft Excel to analyze sales performance and track key business metrics. The dashboard presents sales trends, revenue, profit, and product performance through charts, pivot tables, and visual reports to support data-driven decision-making.
Tools Used: Microsoft Excel, Pivot Tables, Charts, Slicers, Data Cleaning, Data Visualization.
Key Features:
Sales and profit analysis
Product and category performance
Monthly sales trends
Interactive filters and slicers
KPI tracking and data visualization
Objective: To transform raw sales data into meaningful insights and help businesses monitor performance and identify growth opportunities.
